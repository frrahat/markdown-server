      Keyboard shortcuts

      j / kScroll down / up
      d / u, Ctrl+d / Ctrl+uHalf page down / up
      gg / GTop / bottom of the document
      /Find in document (Enter keeps matches, Esc cancels)
      n / NNext / previous match
      EscClear find highlights
      Ctrl+pFuzzy-filter files by path; arrows or Ctrl+n/p to move, Enter to open, Esc to clear
      j k h l or arrowsMove in the file tree (when it has focus)
      EnterOpen file / toggle folder in the tree
      ?This help

      Find is smartcase: case-insensitive unless the query contains a capital letter.
